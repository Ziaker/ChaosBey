# Bey Visual Concepts — Round 1 (archived)

A frozen copy of the first round of nine visual concepts, kept for reuse. The owner rejected this round as a whole: most models read as two pieces, a plate on a stick. Defense C was the exception, and it became the reference for round 2 in `../bey-visual-concepts/`.

Individual parts (rings, tips, cores, …) can still be imported or copied from `src/parts/`. This folder is self-contained and imports nothing from the game or from round 2. Do not edit it; new work goes in the active prototype.

Open it with:

- `npm run dev`, then go to `/prototypes/bey-visual-concepts-round1/`
- or the production preview: `/ChaosBey/prototypes/bey-visual-concepts-round1/`
